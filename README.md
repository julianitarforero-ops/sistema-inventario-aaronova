# Sistema de inventario – Aaronova Accesorios

## Descripción

Sistema de inventario desarrollado para Aaronova Accesorios como proyecto de formación del programa Análisis y Desarrollo de Software del SENA.

El sistema busca mejorar el registro, actualización y seguimiento de la mercancía, permitiendo optimizar el control de las existencias y disponer de información confiable para la toma de decisiones.

## Problemática

Aaronova Accesorios presenta dificultades relacionadas con el manejo manual del inventario. Esta situación puede generar inconsistencias en los registros, información desactualizada, baja trazabilidad y dificultades para consultar las existencias disponibles.

## Objetivo general

Desarrollar un sistema de inventario para Aaronova Accesorios que permita gestionar de manera eficiente el registro, actualización y seguimiento de la mercancía, con el fin de optimizar el control de existencias, fortalecer la organización del inventario y garantizar información confiable para la toma de decisiones.

## Objetivos específicos

* Agilizar los procesos de gestión del inventario mediante la identificación de falencias y necesidades relacionadas con el registro, control y seguimiento de la mercancía.
* Incorporar funcionalidades de reportes y consulta que faciliten el control del inventario y apoyen la toma de decisiones.
* Automatizar el control de entradas, salidas y existencias de la mercancía.
* Administrar el ingreso de usuarios mediante un sistema de registro de roles, correo y contraseña.

## Módulos del sistema

### 1. Autenticación y usuarios

Permite gestionar el acceso al sistema mediante usuarios y roles.

### 2. Gestión de productos

Permite registrar, actualizar, consultar y organizar la información de los productos.

### 3. Entradas y salidas

Permite controlar los movimientos de ingreso y salida de mercancía y actualizar el inventario.

### 4. Manejo de productos

Permite supervisar la disponibilidad de productos e identificar referencias agotadas o con bajo inventario.

### 5. Reportes

Permite generar informes sobre el estado del inventario, los movimientos de mercancía y la disponibilidad de productos.

## Pregunta del proyecto

¿De qué manera puede optimizarse la gestión del inventario en la empresa Aaronova Accesorios para reducir los errores en el registro, seguimiento y control de los productos?
